# CHARM AI — Your AI Wingman

A mobile-first dating and conversation assistant concept built with React and Vite.

## Features in this frontend demo
- Home dashboard and navigation
- Charm Chat with style selection and sample reply ideas
- Rizz Studio with seven conversation styles
- Chat Analyser demo reflection
- Charm Academy with lesson progress
- Profile and saved replies (session only)

## Run locally
```bash
npm install
npm run dev
```

## Important
This is a frontend demo. Reply suggestions are local sample content, not generated by a connected AI model. There is no account backend, cloud storage, subscription billing, or production data processing yet. Do not paste sensitive personal information. Before public launch, add a secure AI backend, privacy policy, age controls, security review, and appropriate legal/compliance checks.
